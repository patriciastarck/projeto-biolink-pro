# 🌿 BioLink Pro — Nutrição & Bem-Estar

Página de links (*Link in Bio*) desenvolvida com foco em **Nutrição e Cuidado Integral da Saúde**, reunindo canais de atendimento, conteúdos educativos e redes sociais em uma interface limpa, responsiva e acessível.

🔗 **Acesse o projeto online:** [https://patriciastarck.github.io/projeto-biolink-pro/](https://patriciastarck.github.io/projeto-biolink-pro/)

---

## 🎯 Sobre o Projeto

Desenvolvido como entrega prática da trilha **trendsIT**, o **BioLink Pro** tem como objetivo consolidar os fundamentos do desenvolvimento web front-end sem o uso de frameworks ou JavaScript. A interface foi pensada na abordagem *Mobile-First*, priorizando legibilidade, contraste adequado e identidade visual acolhedora.

### ✨ Funcionalidades e Destaques
- **Estrutura Semântica:** Uso adequado de `<header>`, `<main>`, `<nav>` e `<footer>` para acessibilidade e SEO.
- **Layout Responsivo:** Alinhamento e distribuição de elementos estruturados com **CSS Flexbox**, adaptando-se perfeitamente a telas de dispositivos móveis e desktops.
- **Identidade Visual Personalizada:** Paleta de cores botânica/terrosa, tipografia *Poppins*, foto de perfil estilizada e efeitos suaves de transição (`:hover`).
- **Navegação Segura:** Links externos configurados para abertura em nova aba (`target="_blank"` com `rel="noopener noreferrer"`).
- **Rodapé Minimalista:** Ícones vetoriais via CSS puro (*Phosphor Icons*) para contato rápido via redes sociais e e-mail.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Semântico)
- **CSS3** (Vanilla CSS, Flexbox, Variáveis CSS)
- **Google Fonts** (*Poppins*)
- **Phosphor Icons** (Folha de estilo CSS)
